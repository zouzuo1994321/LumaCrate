## ✨ 它是什么

一个**本地优先**的 Windows 桌面影视管理软件：借鉴 Emby 的海报墙 / 演员 / 详情页，以及 tinyMediaManager 的本地管理与强化关联搜索。全部界面用 PySide6 实现，PyInstaller 打成**单个 exe**，双击即用。

- **纯本地、不联网刮削**：只读取影片目录里已刮削好的 `.nfo`，不访问任何在线元数据服务；片单、番号、演员信息完全留在自己机器上。
- **演员 / 导演独立成表（Emby 模式）**：`people` 表独立存储，可从任意演员 / 导演反查其全部作品。
- **单文件 exe**：`--onefile --windowed`，无需安装、无需 Python。

## 🚀 下载与运行

**无需安装 Python、无需联网、不依赖浏览器。**

1. 到 [Releases](../../releases) 下载 `流明盒-v1.40.11-2610130074.exe`（约 57 MB，单文件）。
2. 双击运行 —— 首次启动会在 **exe 同目录** 生成 `index_data/`（索引库）与 `settings.json`。
3. 运行期数据生成在 **exe 同目录**，可随 exe 一起移动。

> ⚠️ 因为是 PyInstaller 单文件 exe，部分杀软会误报。源码完全开放，可自行核对或从源码构建。

## 🖱️ 怎么用

- **建立媒体库**：工具 → 媒体库 → 新建媒体库，添加本地影片目录（建议目录内已备 `.nfo`）。
- **扫描建索引**：保存后软件读取 nfo 建立本地索引（演员 / 导演 / 标签等）。
- **浏览**：海报墙按媒体库 / 收藏 / 合集切换；演员库、导演库可反查作品。
- **智能推荐**：
  - 向量编辑 → 从画像自动填充 / **从收藏的演员自动填充**，调出你的内容偏好；
  - 推荐墙「引导向量」输入艺人名 / 标签，临时偏向往某方向。
- **AI 引擎**（可选）：基础工具 → AI引擎设置，开启「自动拉起 Ollama」或点「立即启动」，检测本地引擎后在下拉选调用模型。

## 🎨 界面上的几处讲究

这些细节是「流明盒」观感与稳定性的来源，单独拎出来说明。

### ① 冻结式布局：窗口恒定、内容不重排

工具窗固定默认 **1320×960**，打开即这个尺寸；窗口仍可手动拖拽（下限 560px，只为不把左侧导航挤没）。每页绘制在固定宽 **1170px** 的画布上（= 1320 − 150 导航），拉宽窗口只在右侧留白、组框宽度一字不变；拉高时多余高度落在页面脚下，子模块高度锁定、不随窗口膨胀。这套「滚动区 → 固定宽画布 → 页面」三层结构（v1.40.7 引入）彻底消除了「切页窗口自己跳高矮 / 内容被硬切」两类老问题。

### ② 强调色派生：12 色任选、全链路统一

「外观」里 12 种高亮色可选。运行日志底色、进度环、选中流光、启动画面进度条全部由 `rgba(__ACCENT__, …)` 派生（HLS 空间只调明暗 / 饱和度），改一处全链路跟着变，不会出现「某块颜色还是写死的旧色」。

### ③ 执行日志与运行日志同款样式（v1.40.11）

「工具 → 演员刮削 → 执行」的日志框与「工具 → 数据与日志 → 运行日志（实时）」统一为同一套样式：等宽字体（Consolas / Courier New / monospace）+ 半透明深色底 `rgba(0,0,0,0.25)` + 浅色字 `#d9cfbf` + **不自动换行**。两条框共用同一个 `LOG_BOX_STYLE` 常量，观感一致、改一处两处同变。（仅样式复刻，执行框仍显示实时 `[i/total]` 进度行，不做 app.log 实时 tail。）

### ④ Fusion 风格守卫：真机才画得出控件

Windows 11 默认的 `windows11` QStyle 是四个风格里**唯一画不出 `QTreeView::indicator`** 的——演员检测的复选框在离屏（`offscreen`）后端全绿，真机却整列空白。修法：`main.py` 建完 `QApplication` 立刻 `setStyle(QStyleFactory.create("Fusion"))`。立下铁律：**凡是验「控件是否真画出来」的探针，必须在 `QT_QPA_PLATFORM=windows` 下跑**，离屏与真机结论可差出一个 QStyle。

### ⑤ 数据统计与实时状态面板

侧栏底部「数据统计」与「实时状态」面板均可在「外观」里开关。实时状态走**进程级单例**采集线程（CPU / 内存 / 网络 / GPU / Ollama，含 psutil 优先 + ctypes 兜底降级链），避免面板重建时连带销毁运行中线程导致进程崩溃（v1.27.0 真机缺陷的根治）。

## 🔍 核心功能深挖

### 6️⃣ 演员刮削与 Cloudflare 验证助手

「工具 → 演员刮削」提供全量 / 增量 / 补齐 / 修复四种模式，仅补齐演员资料并下载头像，不修改任何媒体文件。代理有**显式开关**（关闭 = 纯直连，不读系统代理）；站点连接失败时给出 **TCP → TLS → HTTP 正文（WAF 挑战页）→ 应用层** 四层判因，并按数据源指出针对该站挑战机制的出路。Cloudflare 验证助手用**内置 WebView2 浏览器**过一次人机校验（窗口置顶 + 即时反馈），cookie 自动取回注入并复用，也可单独点「读取 Cookie」复查，无需 F12。

### 7️⃣ 智能推荐与引导向量

推荐算法简化为「普通 / AI 单选 + 引擎状态 + 检测」；引导向量支持**模糊匹配**（含子串的标签 / 片商 / 系列全部加强），并可**中文自动翻译成日文再匹配**（轮奸 → 輪姦、三上悠亚 → 三上悠亜）。向量编辑支持「从画像自动填充」与「从收藏的演员自动填充」，可选统计范围 / 取前 N / 权重 / 逐维度启用并记住偏好。

### 8️⃣ 演员检测（罗马音归并 + AI 复核 + 多选批量合并）

普通算法做罗马音归并 / 别名互指，AI 算法（本地 Ollama，可选依赖）复核「不同艺名同一人」。结果树左侧「选择」复选框列支持 **Shift 区间 / Ctrl 逐点**多选，一键把勾选的「建议合并」簇按各自默认保留艺名批量合并（`db.merge_people`，只补空字段 + 合并别名与 meta，不动视频 / nfo）。

### 9️⃣ 画像概览（高频榜 / 分布 / 八维偏好雷达）

基于收藏画像的高频标签 / 片商 / 系列 / 演员 / 导演榜，配八维偏好雷达图。长 CJK 条目名用**像素级**对齐（按 `QFontMetrics.horizontalAdvance` 真实宽度预算，而非字符数），计数右对齐、条形用当前高亮色，杜绝折行 / 溢出 / 重叠。

### 🔟 单文件 exe 与本地优先架构

PyInstaller `--onefile --windowed` 打成单个 exe；刮削只读本地 `.nfo`，不联网。演员库 `people` 表独立（Emby 模式），可从任意人物反查作品；数据库层用 SQL 下推 + 增量渲染扛 5W+ 片，排序与索引逐列对齐避免每页全表扫描。

### 1️⃣1️⃣ 数据管理与隐私

全部索引、设置、日志生成在 **exe 同目录**（可随 exe 移动）；导出 / 导入支持数据备份与四页扫描结果续接。所有数据留在本机，不向任何在线服务上报；AI 引擎提示词做脱敏（不含盘符 / 目录 / 番号 / 文件名）。

## 🛠️ 开发与打包

### 环境

- Python 3.13 + PySide6（Qt 6）+ PyInstaller 6.x
- 可选：`psutil`（本机指标，含 ctypes 兜底，可安全进单文件 exe）、`curl_cffi`（浏览器 TLS 指纹，降级链可选依赖）、Ollama（本地 AI 引擎，可选）

### 常用命令

```bash
# 源码态直接跑
python src/main.py

# 打成单文件 exe（产出 流明盒-vX.Y.Z-YYMMDDNNNN.exe，落到根目录与 history/）
python build_exe.py
```

- 打包参数（`--onefile --windowed`、图标 `logo.ico`、捆绑 `logo-4.png`）写在 `build_exe.py`，不用命令行长参数。
- 最新版 exe 放根目录，历史版本自动归档到 `history/`。

### 离屏冒烟（铁律）

`dev/` 下为离屏（`QT_QPA_PLATFORM=offscreen`）冒烟脚本，不需要真实显示器：

| 脚本 | 作用 |
| --- | --- |
| `smoke_v1411.py` | v1.40.11 冒烟：执行日志框样式 == 运行日志框样式（同 `LOG_BOX_STYLE` + `NoWrap`）、版本 v1.40.11 (2610130074)；v1.40.10 六条 + v1.40.9 锁高/无滚轴回归仍成立 |
| `live_verify_v1411.py` | v1.40.11 真机验收：跑真实 exe，逐页切换断言窗口尺寸恒定、核查 `app.log` 零未捕获异常（点破坏性按钮前必须校验落点） |
| `smoke_v1408.py` | v1.40.8 冒烟：页面内容完整显示回归（冻结只钉宽 + 无横滚轴） |
| `smoke_v1407.py` | v1.40.7 冒烟：固定尺寸 + 内容冻结回归（59 项） |
| `smoke_v1400.py` | v1.40.0 冒烟：刮削页改版回归（统计独立模块 / 代理开关 / cookie 注入） |

> ⚠️ 交付铁律：冒烟以**数据断言**取代肉眼截图；交付物只含 exe + README + dev 脚本，**不附界面截图**。凡验「控件是否真画出来」的探针，必须在 `QT_QPA_PLATFORM=windows` 下跑（离屏与真机结论可差出一个 QStyle）。

### 排障

- **杀软误报**：PyInstaller 单文件 exe 常被误报，源码开放可自行核对或从源码构建。
- **构建号自增**：每次 `build_exe.py` 会把 `version.py` 的 `BUILD_SEQ` 末四位 +1（跨日连续、不按日归零），并同步顶部注释、README 徽章与下载名。
- **离屏平台陷阱**：离屏 `offscreen` 后端默认 QStyle 是 `windows11`（画不出 `QTreeView::indicator`），必须在 windows 后端子进程里量控件像素才可信。
