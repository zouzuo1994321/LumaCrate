### v1.34.2 (Build 2609250050) — 2026-09-25

> 主题：**2 条反馈 —— 「统计范围」组框下方留白太多 / 「取前 N 个」上限 200 改为 999 且真正支持到 999**。

- **反馈 1 ·「统计范围」组框高度收紧，去掉下方留白**
  - **现象**（用户截图，已用红框标出）：工具 → 智能推荐 → 向量编辑 → 「从画像自动填充…」的
    参数面板里，「统计范围」组框比它的实际内容高出不少，下方空出一大块。
  - **根因（逐控件量化几何后才定位到）**：真因**不在**组框尺寸、也不在 `_fit_height()`，
    而是「统计范围」下面那行说明 —— `lb_scope_tip` 这个 `QLabel` 开了 **`setWordWrap(True)`**。
    `QLabel` 一旦开启自动换行，它的 `sizeHint` 会按**多行**去估算高度，`QFormLayout`
    遂把它拉伸到约 **3 行高**：实测 v1.34.1 该标签高 **60px**、v1.34.2 初版仍有 **45px**，
    而里面的文字其实只有**一行 ~17px**。多出来的那 40 多像素，就表现为组框下方的空白。
  - **修法**：
    - `lb_scope_tip.setWordWrap(False)` —— 关掉自动换行，`sizeHint` 回归真实单行；
    - `lb_scope_tip.setFixedHeight(fontMetrics().lineSpacing() + 3)` —— 再把高度**定死一行**，
      `QFormLayout` 无法再拉伸它；三档范围文案已在 `_refresh_est` 里压成单行，故不会裁字；
    - 媒体库名过长（> 12 字）时**截断加省略号**，避免把面板撑宽；
    - `g1` / `g2` 两个组框钉 `SizePolicy(Preferred, Fixed)`（不被外层布局拉伸），组框内边距
      收紧为 10/8/10/8、行距 6，并去掉 `_build()` 末尾的 `addStretch`。
  - **实测**（同为离屏、同字体、逐控件量几何）：

    | 指标 | v1.34.1 | v1.34.2 |
    | --- | --- | --- |
    | `lb_scope_tip` 高度 | 60 px | **19 px** |
    | 「统计范围」组框高度 | 145 px | **102 px（−43 / −30%）** |
    | 整个对话框高度 | 613 px | **570 px** |

  - 初版（Build 2609250049）曾试图用 `_content_height()` 逐项手算高度，因**严重低估**
    （算出 101px）会导致内容裁切，已放弃；改回 Qt 的 `sizeHint` 并**从标签本身**入手，才是正解。

- **反馈 2 ·「取前 N 个」上限由 200 改为 999，并真正支持到 999**
  - **现象**：面板上「取前 N 个」实测**最多只能写到 99**（第 3 位数字输入不进去）；
    即使填了更大的数，实际入库的高频榜也**只到 30 条**。
  - **根因有两端，都得修**：
    - **端一（面板）**：SpinBox 原先带 `setSuffix(" 个")`，带后缀时「999 个」比「999」宽，
      在 `SPIN_MAX_W` 的限宽下**第 3 位被吞**，于是只能写 2 位。
      **修法**：去掉 `" 个"` 后缀，三位数字「999」即可完整显示并可输入。
    - **端二（数据）**：`insight.Portrait.build()` 里各高频榜写死了 `most_common(30)`
      （片商是 20）做截断，所以面板即便填 999，**库里也只写得出 30 条**。
      **修法**：`config.Settings.AUTOFILL_TOP_RANGE` 上限由 `200` 改为 `999`，并新增模块级
      `insight.PORTRAIT_TOP = AUTOFILL_TOP_RANGE[1]`，把 5 个可见榜单（标签 / 片商 / 系列 /
      演员 / 导演）的 `most_common` **全部对齐到它**（标签用 `MAX_TAGS`，由 600 提到 1200
      留余量）。**两处同源**，以后改上限会自动联动。

- **验证**：`dev/smoke_v1342.py` 离屏冒烟 **17 条断言全过 / 0 失败** —— 覆盖
  `AUTOFILL_TOP_RANGE == (1, 999)`、`PORTRAIT_TOP == 999`、`most_common(999)` 真能返回 999 条、
  `items[:999]` 长度 999、SpinBox `maximum == 999` 且 `suffix == ""`、三位数字完整显示、
  "999" 能进 `_plan()`、「统计范围」组框 `SizePolicy == Fixed` 且不再虚高（≤ 140px）、
  `lb_scope_tip` 不换行且恒为 1 行高。
