## 反馈 2 —— 白条（本版最值得记的一条）

- **根因**：`LazyGrid._update_head()` 首行是 `if not self._toolbar_ready: return`，
  而 `mark_toolbar_placed()` **全项目只有两处调用**（main_window 的 `_wall_page` / `_view_smart`）。
  演员库 / 导演库 / 最近播放 / 合集这四页的 LazyGrid **从未调** → 函数一次没跑过
  → `self.head` 保持 Qt 默认可见 → 里面那个 `maximum` 从未设置、无进度的
  `QProgressBar`（`setFixedHeight(6)` / `setMaximumWidth(260)`）画成一条**空槽灰白细条**。
- **修法（双保险，缺一不可）**：`LazyGrid.__init__` 里 `self.head.setVisible(False)` +
  `self.bar.setVisible(False)`；`_update_head()` 的未接管分支**主动 hide** 而非只 `return`。
- **定位链**：用户截图放大确认是**细横条** → `PrintWindow` 抓无遮挡帧逐行扫亮度
  → 发现「空数据页面没有白条」→ 排除卡片区、锁定工具行 → `grep mark_toolbar_placed` 收尾。
- **真机硬证据**：工具行右侧 `(960,1300,66,112)` 区域，修复后 **亮像素 0/15640、峰值 57.7**
  （阈值 60），修复前实测 **72~81 vs 背景 26~33**。
- **通用教训**：`QWidget` 容器默认**可见**。**凡「懒初始化 + 门闩」的容器，构造时必须显式
  `setVisible(False)`，不能依赖初始化函数来隐藏它** —— 那个函数可能永远不会被调到。
  （同族：v1.21.1 的 `more_btn`/`refresh_btn` 无父时 `setVisible(True)` 变顶层小窗。）

## 反馈 1 —— 四页结果导入导出

- 四个模块各一对纯 Python 函数（不 import Qt）：`duplicates` / `imagedetect` / `actorcheck` /
  `tagopt` 的 `export_json` / `import_json`。
- **统一信封**：`{"_app": "LumaCrate", "_kind": "…", "_format": 1, "report"/"result"/"plans": …}`。
  导入先验 `_kind`、再验 `_format`，**同时兼容 v1.32.0 的裸格式**。
- 页面侧属性名（真机/冒烟按这些找）：`dd_exp_result` / `dd_imp_result`（重复检测，在 `ui_settings`）、
  `btn_to_exp` / `btn_to_imp`（标签优化，同文件）、`exp_btn` / `imp_btn`（图像/演员检测各在自己的 ui_ 文件）。
- **三个真被抓到的序列化坑**（冒烟 C 段就是为此写的，下次改这四个模块务必重跑）：
  1. `actorcheck` 的 `_occ` 键是 **tuple** → `json.dump` 报
     `TypeError: keys must be str, … not tuple`。**簇自身**也有 `_occ`，只剥成员层不够
     → 必须**递归** `_plain()`（剥 `_` 前缀 + 非字符串键转字符串 + tuple 转 list）。
  2. `tagopt` 的 `translated` 是**嵌套二元组** `("中出し", "中出")`，原「一层 str 兜底」
     把整个 tuple `str()` 掉 → 落盘成 `"('中出し', '中出')"` → 导入回来解包成 **13 个字符**。
  3. `duplicates.export_json` 直接把 `report.as_dict()` 塞信封，而 `as_dict()` 把
     `scanned` / `missing` / `generated_at` 放在 **`summary` 子字典**里 → 导入回来顶层全是默认值，
     汇总行写成「核对 **0** 部作品」。**导出用 `as_dict()` 时，导入读顶层字段，两者结构必须对齐。**
- 导入**复用各自的 `_on_done`**（重复检测是 `_on_dedupe_done`），所以结果树 / 汇总行 /
  执行写入 / 导出 CSV 全部照常可用；AI 结论随 `ai` 字段回来。
