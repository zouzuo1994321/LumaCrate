# dev/history —— 历史离屏冒烟脚本（归档）

v1.45.0 起，`dev/` 根目录**只保留当前发布门槛** `smoke_v1430.py`；其余脚本全部移到本目录。

## 为什么要归档

这些脚本各自绑定**当时**的界面形态与数据源数量，例如：

- `smoke_v1421/1422.py`：期望 3 个数据源、列表 184px、把手只有圆点没有虚线；
- `smoke_v1416_browser_session.py`、`smoke_v1408.py` 等：绑定当时的页面结构；
- 更早的 `smoke_v110…v1395.py`：连版本号与配置键都对不上。

在当前代码上运行它们**必然失败**（不是回归，是"需求本身变了"）。留在根目录只会让人误判，
所以统一归档。

## 当前怎么验

```bash
# 1) 发布门槛：离屏全量冒烟（GUI、临时库，不联网）
python dev/smoke_v1430.py          # 期望：SMOKE_V1430_ALL_OK，112/112

# 2) 纯函数单测（不启动 GUI、不联网、不碰真实库）
python dev/test_units.py           # 期望：UNIT_ALL_OK，21/21

# 3) 真机自检（需要真实 exe）
python dev/_scratch/exe_selfcheck_v1451.py
```

## 归档脚本还能用吗

能，但只能作为**历史证据**参考：它们的断言值就是当时版本的验收标准。
若要复用里面的探针手法（像素测量、几何断言、泄漏计数），把思路搬到新脚本里，
不要直接跑旧脚本求"全绿"。
